# PUF Authentication Stack

Open reference stack for PUF-rooted authentication designed for low-bandwidth, intermittently connected sensor networks.

This repository will host:
- Specification and reference library (fuzzy extractor, hash-chain tokens, revocation, command authentication)
- Simulation harness
- Open-hardware readout rig design files
- Measurement datasets

**Status**: Repository created in preparation for NLnet Restack proposal (deadline 3 November 2026).
