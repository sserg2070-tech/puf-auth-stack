# PUF Authentication Stack

Open reference stack for PUF-rooted authentication designed for low-bandwidth, intermittently connected sensor networks.

This project is being developed as part of a proposal to the NLnet Restack programme.

## Components

- Specification and reference library (fuzzy extractor, hash-chain tokens, revocation lists, command authentication)
- Simulation harness
- Open-hardware readout rig
- Public measurement datasets

## Status

Repository created in preparation for the NLnet Restack call (deadline 3 November 2026).  
Core library and tools will be released under free licences.
